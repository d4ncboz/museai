## Profile template (one per character, stored in `series/bible.md`)

```
### 名字 pinyin - role
- Age / birthday / zodiac
- Family: parents, siblings, spouse/children, household
- Home + job / livelihood
- Face (fixed): shape, eyes, brows, nose, lips, skin tone, mole/scar/glasses
- Hair + accessories (fixed): style, colour, ornaments
- Costume palette: signature colour + 3 occasion sets (daily, festival, work)
- Personality: 3 traits; strength; flaw; fear; ambition
- Speaking style: sentence length, pet words, tone, how they say sorry / thanks / no
- Secret(s): what, who knows, when it may surface
- Relationships: name - kind - current state - history
- Arc: start state -> milestones by season -> end state
- Everyday habits: food they love, routine, small gestures (used for romance/care beats)
```
